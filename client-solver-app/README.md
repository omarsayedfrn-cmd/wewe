# Solver Client App (Native Android Kotlin)

تطبيق العميل لنظام أندرويد مكتوب بلغة **Kotlin**، مخصص للطلاب والمستخدمين النهائيين للاتصال بخدمات الحل ومتابعة المهام وحالة الحسابات.

---

## 📋 المميزات
- واجهة مستخدم سلسة وعصرية للعملاء.
- إدخال أكواد التفعيل والتحقق من صلاحيتها.
- إرسال طلبات الحل إلى السيرفر ومتابعة الإنجاز لحظة بلحظة.

---

## 🛠️ متطلبات البناء
- Android Studio
- JDK 17 أو 21
- Android SDK Platform 34

---

## 🚀 التجميع
```bash
./gradlew assembleDebug
```
