# QUREO2 English Python Solver (CLI)

محرك حل تلقائي ذاتي الاكتشاف لمنهاج **بايثون إنجليزي** على منصة **QUREO2** (`python_short_en` — 10 فصول، 50 دايموند).

---

## 📋 المميزات
- **PERFECT 50/50**: إنجاز الفصول الـ 10 بعلامة كاملة (5 دايموند للفصل).
- **ذاتي الاكتشاف بدون answers.json**: جولة تعلّم تقرأ الإجابات الصحيحة من رد المصحح، وجولة تطبيق تعيد الإجابة بيها (الإعادة مجانية و`best_correct_count` هو الأقصى).
- **فصول الاختبار (test)**:arResult endpoint يكشف الصح بعد اكتمال المحاولة.
- **تحديد فصول مرن**: دعم البدء من أي فصل (1–10).

---

## 🚀 طريقة الاستخدام

### المتطلبات:
- `curl`
- `jq`
- `python3`

### التشغيل:
```bash
./solve.sh <STUDENT_ID> <PASSWORD> [START_CHAPTER]
```

### أمثلة:
- حل جميع فصول البايثون الإنجليزي (1 إلى 10):
  ```bash
  ./solve.sh 482438443 'pass'
  ```
- حل من الفصل 5:
  ```bash
  ./solve.sh 482438443 'pass' 5
  ```
