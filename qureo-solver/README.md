# QUREO JavaScript Solver (CLI)

سكربت ومحرك حل تلقائي فائق السرعة لمنهاج برمجة جافاسكريبت على منصة **QUREO** (54 فصلاً - 270 ماسة).

---

## 📋 المميزات
- **حل كامل بالعلامة القصوى**: إنجاز جميع التحديات والمهام بـ 5 ماسات لكل فصل.
- **تخطي الحماية**: تسجيل دخول ذكي واستخراج جلسة `OAuth2` وإرسال حلول الأسئلة بدقة مطابقة لإجابات المنصة.
- **دعم النطاقات المخصصة**: إمكانية البدء من فصل محدد وحتى فصل محدد.

---

## 📂 محتويات المجلد
- `solve.sh`: سكربت Bash التنفيذي الرئيسي الذي يتولى تسجيل الدخول وإرسال الحلول عبر `curl` و `jq`.
- `answers.json`: قاعدة البيانات النموذجية لجميع كود وفصول المنهج الـ 54.
- `build_explain.py` & `build_cover.py`: أدوات مساعدة لتوليد وتجهيز شروحات الدروس والتغطية الشاملة.
- `explain/`: ملفات الشروحات التفصيلية لكل تحدي.

---

## 🚀 طريقة الاستخدام

### المتطلبات:
- `curl`
- `jq`
- `bash`

### التشغيل:
```bash
./solve.sh <STUDENT_ID> <PASSWORD> [START_CHAPTER] [END_CHAPTER]
```

### أمثلة:
- حل المنهج بالكامل (من الفصل 1 إلى 54):
  ```bash
  ./solve.sh st_123456 pass123
  ```
- حل الفصول من 10 إلى 20 فقط:
  ```bash
  ./solve.sh st_123456 pass123 10 20
  ```
