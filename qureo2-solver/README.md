# QUREO2 Python Solver (CLI)

سكربت ومحرك حل تلقائي فائق السرعة لمنهاج برمجة بايثون المختصر على منصة **QUREO2** (25 فصلاً - 125 ماسة).

---

## 📋 المميزات
- **حل كامل بالعلامة الكاملة**: إنجاز 25 فصلاً في لغة بايثون والحصول على 125 ماسة كاملة.
- **تخطي التحقق وحقن الإجابات**: تنفيذ تسلسل المهام البرمجية والاختبارات التراكمية.
- **تحديد فصول مرن**: دعم البدء من أي فصل والانتهاء عند أي فصل.

---

## 📂 محتويات المجلد
- `solve.sh`: سكربت Bash التنفيذي لحل منهاج Python Short.
- `answers.json`: قاعدة بيانات الإجابات الصحيحة للفصول الـ 25.

---

## 🚀 طريقة الاستخدام

### المتطلبات:
- `curl`
- `jq`
- `bash`

### التشغيل:
```bash
./solve.sh <STUDENT_ID> <PASSWORD> [START_CHAPTER] [END_CHAPTER]
```

### أمثلة:
- حل جميع فصول البايثون (1 إلى 25):
  ```bash
  ./solve.sh st_987654 pass123
  ```
- حل الفصول من 5 إلى 15:
  ```bash
  ./solve.sh st_987654 pass123 5 15
  ```
