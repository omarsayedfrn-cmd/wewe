# QUREO JavaScript English Solver (CLI)

محرك حل تلقائي ذاتي الاكتشاف لمنهاج **جافاسكريبت إنجليزي** على منصة **QUREO** (`javascript_en` — 54 فصلاً، 270 دايموند).

---

## 📋 المميزات
- **PERFECT 270/270**: إنجاز الفصول الـ 54 بعلامة كاملة (5 دايموند للفصل).
- **ذاتي الاكتشاف بدون answers.json**: جولة تعلّم تقرأ الإجابات الصحيحة من رد المصحح، وجولة تطبيق تعيد الإجابة بيها (الإعادة مجانية و`best_correct_count` هو الأقصى).
- **أنواع الفصول ديناميكية**: نوع الاختبار (review/test) يُجلب من API القسم مباشرة بدون hardcode.
- **فصول الاختبار (test)**: الـ result endpoint يكشف الصح بعد اكتمال المحاولة.
- **تحديد فصول مرن**: دعم البدء من أي فصل (1–54).

---

## 🚀 طريقة الاستخدام

### المتطلبات:
- `curl`
- `jq`
- `python3`

### التشغيل:
```bash
./solve.sh <STUDENT_ID> <PASSWORD> [START_CHAPTER]
```

### أمثلة:
- حل جميع الفصول (1 إلى 54):
  ```bash
  ./solve.sh 482438443 'pass'
  ```
- استكمال من الفصل 46 (اللي بعد محلول):
  ```bash
  ./solve.sh 482438443 'pass' 46
  ```

## 📐 البنية المكتشفة
- القسم: `2` — الفصول: `30001`–`30054`
- نوع الفصول: `review` عدا كل فصل اختبار (يُجلب ديناميكياً من `test_type` في رد القسم)
- أسئلة الاختبار (test) ترجع `{}` لكل سؤال، والصح يتجلى من `GET students/chapters/{cid}/test/result` بعد اكتمال المحاولة
