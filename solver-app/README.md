# Solver Native Android App (Kotlin)

تطبيق أندرويد مكتوب بلغة **Kotlin** مع واجهات **Jetpack Compose / XML** ونظام البناء الحديث **Gradle (KTS)**.

---

## 📋 المميزات
- تطبيق هاتف مخصص للتحكم وإجراء عمليات الحل للمنصات التعليمية مباشرة من الجهاز.
- اتصال مباشر بالخدمات وواجهات الـ API.

---

## 🛠️ متطلبات البناء
- Android Studio Iguana / Ladybug أو أحدث
- JDK 17 أو JDK 21
- Android SDK Platform 34

---

## 🚀 التجميع والتشغيل

### عبر Gradle Wrapper:
```bash
./gradlew assembleDebug
```
ملف الـ APK الناتج:
`app/build/outputs/apk/debug/app-debug.apk`
