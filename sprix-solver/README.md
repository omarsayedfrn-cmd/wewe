# SPRIX Financial Literacy Solver (CLI)

محرك وسكربت أوتوماتيكي متكامل لحل مادة الثقافة المالية (Subject 7) على منصة **SPRIX** (الوحدات 19 إلى 24) بنسبة 100% (PERFECT).

---

## 📋 المميزات
- **إجابات نموذجية 100%**: حل جميع أسئلة الفصول والاختبارات النهائية بالعلامة الكاملة.
- **توليد شهادات وتقارير PDF**: استخراج وطباعة تقارير الإنجاز تلقائياً.
- **دعم المعالجة الدفعية (Batch Solving)**: حل واجبات مئات الطلاب تباعاً من ملفات JSON أو CSV.

---

## 📂 محتويات المجلد
- `solve.sh`: سكربت Bash لحل حساب طالب فردي بسرعة فائقة.
- `answers.json`: إجابات الوحدات 19، 20، 21، 22، 23، 24.
- `batch/`: أدوات وسكربتات التشغيل الدفعي لمجموعات الطلاب والمدارس.
- `pdf/`: مولد شهادات الإتمام وتقارير النتائج.

---

## 🚀 طريقة الاستخدام

### المتطلبات:
- `curl`
- `jq`
- `bash`

### التشغيل لحساب فردي:
```bash
./solve.sh <LOGIN_ID> <PASSWORD> [START_UNIT] [END_UNIT]
```

### أمثلة:
- حل المنهج بالكامل (الوحدات 1 إلى 6 / 19 إلى 24):
  ```bash
  ./solve.sh student_abc secret123
  ```
- حل الوحدات من 3 إلى 5:
  ```bash
  ./solve.sh student_abc secret123 3 5
  ```
