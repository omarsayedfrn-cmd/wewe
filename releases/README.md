# Releases & Distribution Binaries

يحتوي هذا المجلد على حزم التطبيقات المترجمة الجاهزة للتثبيت المباشر على الأجهزة.

---

## 📦 الحزم المتاحة:

1. **`SolverBot.apk`**:
   - أحدث إصدار من تطبيق أندرويد المتكامل (Relay Engine + Telegram Bot Poller + Local Solvers).
   - يعمل على معمارية `arm64-v8a` (Android 7.0+ / API 24+).
   - طريقة التثبيت: `adb install -r SolverBot.apk`.

2. **`solver-app-apk.zip`**:
   - حزم وأرشيف تطبيق الأندرويد الأصلي (Kotlin Native).
